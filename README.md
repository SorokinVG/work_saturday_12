## Описание

Проект содержит две функции для обработки списка словарей с информацией о банковских операциях:

- **`filter_by_state`** — фильтрует операции по значению ключа `state` (например, `EXECUTED` или `CANCELED`);
- **`sort_by_date`** — сортирует операции по дате (по убыванию или возрастанию).

Обе функции возвращают **новый список** и не изменяют исходные данные. Тип элемента описан через `TypedDict` (`Transaction`), что позволяет статическим анализаторам (mypy, pyright) проверять структуру данных.

## Требования

- Python **3.10+**
  - Используется синтаксис `list[Transaction]` (PEP 585)
  - `TypedDict` импортируется из `typing`

Внешних зависимостей нет — только стандартная библиотека.

## Использование

```python
from typing import TypedDict


class Transaction(TypedDict):
    id: int
    state: str
    date: str


data: list[Transaction] = [
    {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
    {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
    {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},
    {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"},
]

# 1. Фильтрация по статусу по умолчанию (EXECUTED)
executed = filter_by_state(data)
print(executed)

# 2. Фильтрация по явно указанному статусу (CANCELED)
canceled = filter_by_state(data, "CANCELED")
print(canceled)

# 3. Сортировка по дате по убыванию (сначала новые)
sorted_desc = sort_by_date(data)
print(sorted_desc)

# 4. Сортировка по дате по возрастанию (сначала старые)
sorted_asc = sort_by_date(data, reverse=False)
print(sorted_asc)
```

## API

### `filter_by_state`

```python
def filter_by_state(
    data_list: list[Transaction], state: str = "EXECUTED"
) -> list[Transaction]:
    ...
```

Фильтрует список словарей по значению ключа `state`.

| Параметр    | Тип                 | По умолчанию | Описание                        |
|-------------|---------------------|--------------|---------------------------------|
| `data_list` | `list[Transaction]` | —            | Список словарей для фильтрации  |
| `state`     | `str`               | `"EXECUTED"` | Значение статуса для фильтрации |

**Возвращает:** новый список словарей, у которых `state` совпадает с переданным значением.

**Особенности:**
- Используется `.get("state")`, поэтому отсутствие ключа `state` не приводит к ошибке — такой элемент просто не попадёт в результат.

---

### `sort_by_date`

```python
def sort_by_date(
    data_list: list[Transaction], reverse: bool = True
) -> list[Transaction]:
    ...
```

Сортирует список словарей по значению ключа `date`.

| Параметр    | Тип                 | По умолчанию | Описание                                                    |
|-------------|---------------------|--------------|-------------------------------------------------------------|
| `data_list` | `list[Transaction]` | —            | Список словарей для сортировки                              |
| `reverse`   | `bool`              | `True`       | `True` — по убыванию (сначала новые), `False` — по возрастанию |

**Возвращает:** новый отсортированный список словарей.

**Особенности:**
- Даты сравниваются как строки в формате ISO 8601 (`YYYY-MM-DDTHH:MM:SS...`). Для такого формата лексикографический порядок совпадает с хронологическим.
- Если ключ `date` отсутствует **или равен `None`**, используется пустая строка `""` как значение по умолчанию (`item.get("date") or ""`), что предотвращает падение `sorted` при сравнении `None` со строкой.

## Формат данных

Ожидаемый формат элемента списка — `Transaction`:

```python
class Transaction(TypedDict):
    id: int
    state: str      # например, "EXECUTED" или "CANCELED"
    date: str       # ISO 8601: "YYYY-MM-DDTHH:MM:SS.microseconds"
```

Пример:

```python
{
    "id": 41428829,
    "state": "EXECUTED",
    "date": "2019-07-03T18:35:29.512364",
}
```
