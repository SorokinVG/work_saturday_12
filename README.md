# Проект: Обработка банковских транзакций (Homework_10_1)

## Описание проекта
Данный проект представляет собой набор утилит (модулей) на языке Python для обработки и анализа списков банковских транзакций.
Программа позволяет фильтровать операции по их статусу и сортировать их по дате. Данные представлены в виде списка словарей.

## Функциональность
Проект включает в себя модуль `processing`, который содержит следующие функции:

*   **`filter_by_state(data_list, state='EXECUTED')`** — принимает список словарей и опционально значение для ключа `state`. Возвращает новый список словарей, содержащий только те элементы, у которых ключ `state` соответствует указанному значению. По умолчанию фильтрует по статусу `'EXECUTED'`.
*   **`sort_by_date(data_list, reverse=True)`** — принимает список словарей и необязательный параметр, задающий порядок сортировки. Возвращает новый список, отсортированный по дате (`date`). По умолчанию сортировка происходит по убыванию (сначала самые новые операции).
